File formats

Every dump produces the same set under external/ and internal/:

offsets/  Offsets.hpp .cs .json OffsetsHex.json .txt
fflags/   FFlags.hpp .cs .json FFlagsHex.json .txt
misc/     Struct.hpp Types.json

internal/ additionally contains functions/ with callable function addresses (remote events, fires, task functions).

Usage

Offsets are module-relative (RVA). Resolve with the RobloxPlayerBeta base address:

uintptr_t base = get_module_base("RobloxPlayerBeta.exe");
uintptr_t health = base + 0x184; // Humanoid::Health

Running the dumper

Launch swc_panel.exe, join the dump game in Roblox, press FULL DUMP. The panel pulls the latest offsets for every new Roblox version and publishes them here.
